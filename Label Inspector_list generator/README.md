# Label Inspector_LiGen

라벨 검사를 위한 리스트 생성 프로그램입니다.

## 기능

- **파일 업로드**: 3가지 엑셀 파일을 업로드할 수 있습니다
  - 주문일정 체크리스트
  - 제품 품목 번호 리스트  
  - BSC FGD 리스트
- **드래그 앤 드롭**: 파일을 버튼 위로 드래그하여 바로 로딩 가능
- **날짜 선택**: 계층적 날짜 선택기로 연도 > 월 > 일 단위로 복수 선택
- **리스트 생성**: 선택된 날짜에 따라 LOT, PRODUCTS, PN, REF, MFG DATE, EXP DATE, GTIN 정보가 포함된 엑셀 파일 생성
- **미리보기**: 생성된 데이터를 테이블 형태로 미리 확인
- **다운로드**: 생성된 엑셀 파일을 원하는 위치에 저장

## 설치 방법

1. Python 3.7 이상이 설치되어 있어야 합니다.

2. 필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

## 사용 방법

1. 프로그램을 실행합니다:
```bash
python label_inspector_ligen.py
```

2. 좌측 패널의 버튼을 클릭하거나 파일을 드래그하여 엑셀 파일들을 업로드합니다:
   - **주문일정 체크리스트**: '진행수량' 시트가 포함된 엑셀 파일
   - **제품 품목 번호 리스트**: '품목번호리스트' 시트가 포함된 엑셀 파일
   - **BSC FGD 리스트**: '현UPN별' 시트가 포함된 엑셀 파일

3. 주문일정 체크리스트 파일이 로드되면 날짜 선택 영역에 사용 가능한 날짜들이 표시됩니다.

4. 원하는 날짜들을 클릭하여 선택합니다 (체크마크로 표시됨).

5. '리스트 생성' 버튼을 클릭하여 데이터를 생성합니다.

6. 우측 미리보기 패널에서 생성된 데이터를 확인합니다.

7. '다운로드' 버튼을 클릭하여 엑셀 파일을 저장합니다.

## 데이터 처리 로직

### 입력 파일 구조
- **주문일정 체크리스트** ('진행수량' 시트):
  - F열: LOT
  - G열: PN
  - H열: PRODUCTS
  - N열: 국가 정보
  - S열: REF
  - X열: MFG DATE

- **제품 품목 번호 리스트** ('품목번호리스트' 시트):
  - A열: PN
  - L열: GTIN

- **BSC FGD 리스트** ('현UPN별' 시트):
  - M열: REF 값
  - P열: PN

### 출력 파일 구조
생성되는 엑셀 파일의 컬럼 순서:
1. **LOT**: 선택된 날짜의 모든 LOT 값
2. **PRODUCTS**: 해당 LOT의 제품명
3. **PN**: 해당 LOT의 품목번호
4. **REF**: 기본값 또는 일본 제품의 경우 BSC 리스트에서 매칭된 값
5. **MFG DATE**: 제조일자 (YYYY-MM-DD 형식)
6. **EXP DATE**: 유효기간 (제조일자 + 3년 - 1일)
7. **GTIN**: 해당 PN의 GTIN 코드 (텍스트 형식)

## 주의사항

- GTIN 값은 0으로 시작할 수 있으므로 텍스트 형식으로 저장됩니다.
- 일본 제품의 경우 REF 값이 BSC FGD 리스트에서 자동으로 매칭됩니다.
- 파일명은 선택된 날짜를 기반으로 자동 생성됩니다 (예: Label Inspection List_250904.xlsx).

## 문제 해결

- **드래그 앤 드롭이 작동하지 않는 경우**: tkinterdnd2 패키지가 제대로 설치되지 않았을 수 있습니다. 파일 선택 버튼을 사용해주세요.
- **엑셀 파일 로드 오류**: 파일의 시트명이 정확한지 확인해주세요.
- **날짜가 표시되지 않는 경우**: 주문일정 체크리스트 파일의 X열에 날짜 데이터가 있는지 확인해주세요.
