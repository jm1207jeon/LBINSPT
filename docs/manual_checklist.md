# LabelSuite 수동 검증 체크리스트

자동 테스트(pytest 94건)가 커버하지 못하는 실환경 GUI 흐름의 확인 목록입니다.
실데이터(실제 주문일정/품목번호/BSC 엑셀, 라벨 PDF)로 진행하세요.

## 1. 목록 생성 탭
- [ ] 3개 엑셀을 버튼으로 로드 — 로드 중 UI가 멈추지 않는지
- [ ] 날짜 트리에서 월 노드 체크 → 하위 일 전체 선택되는지
- [ ] 리스트 생성 → 미리보기·경고/오류 패널 확인 (2/29 제조분이 있으면 행이
      존재하고 EXP가 2/27인지)
- [ ] 엑셀로 저장 → 파일을 레거시 Label Inspector에서도 열 수 있는지(하위호환)
- [ ] 앱 재시작 → 3개 파일 경로가 자동 복원되는지
- [ ] 구 LiGen과 동일 입력으로 출력 diff — 의도된 차이(2/29 행 존재, 콜론 포함
      REF 보존, GTIN 14자리, STANDARD 컬럼)만 있는지 **[패리티 검증]**

## 2. 검사 탭 — PDF
- [ ] "검사 탭으로 보내기" → 탭 전환 + 목록 자동 로드
- [ ] PDF 열기 → 1페이지 OCR 완료 후 오버레이 표시, 하단 "OCR 완료 n/m 페이지"
      진행 표시가 증가하는지
- [ ] 프리페치 완료 후 페이지 이동 → **딜레이 없이** 즉시 오버레이·카운트 표시
- [ ] LOT 자동 매칭 표시("자동(정확)" 등) + 규격 자동 선택
- [ ] 규격 수동 변경 → 재-OCR 없이 즉시 카운트 재계산
- [ ] 앱 재시작 후 같은 PDF 재오픈 → OCR 즉시 표시(디스크 캐시), AWS 콘솔에서
      Textract 호출이 발생하지 않는지 **[무과금 검증]**
- [ ] 모든 카운트 일치 시 상태가 "합격(PASSED)"인지, 저장 파일명이 `_Passed`인지
- [ ] 저장된 JPEG 색상이 화면과 동일한지 (R/B 반전 없음)
- [ ] 잘못된 AWS 프로필 설정 → 상태바 빨간 "AWS 인증 실패" + OCR 시 오류 팝업

## 3. UI/UX
- [ ] 엑셀/PDF 파일을 창에 끌어다 놓으면 자동 로드되는지
- [ ] ←/→/Home/End 키로 페이지 이동
- [ ] 전체 테마(버튼/테이블/탭)가 일관되게 표시되는지

## 4. 바코드
- [ ] GS1 DataMatrix가 있는 라벨에서 "바코드 검증" 섹션에 GTIN/LOT/날짜
      일치 여부 표시
- [ ] 목록과 다른 라벨을 검사 → 바코드 불일치가 판정을 "확인 필요"로 만드는지

## 5. 이력/리포트
- [ ] 저장할 때마다 이력 탭에 행 추가, 파일 카운터가 재시작 후에도 이어지는지
- [ ] 더블클릭 → 이미지 열림, LOT 리포트 xlsx 내보내기

## 6. 설정
- [ ] 규격 카운트 수정 → 즉시 검사에 반영
- [ ] 컬럼 매핑 수정 → 다음 파일 로드부터 반영
- [ ] AWS "인증 확인" 버튼 동작

## 7. Windows 패키징
- [ ] `packaging\build_win.bat` → `dist\LabelSuite\LabelSuite.exe` 생성
- [ ] 다른 PC(개발 도구 없는)에서 zip 해제 후 실행되는지
- [ ] 설정/이력이 `%APPDATA%\LabelSuite`에 생성되는지
