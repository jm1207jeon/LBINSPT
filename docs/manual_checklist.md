# LaVIS 수동 검증 체크리스트 (Windows 실기)

리눅스 CI의 자동 테스트(Core xunit)가 커버하지 못하는 WPF 화면 흐름의 확인 목록이다.
실데이터(실제 주문일정/품목번호/BSC 엑셀, 라벨 PDF)로 진행하고, 결과는 항목 옆에
날짜·확인자·빌드 식별(About 오버레이의 버전 / README.txt의 SHA-256)을 적는다.

빌드: Actions → "Build LaVIS Windows EXE (C#)" → `LaVIS-<버전>.zip` → 압축 해제 → `LaVIS\LaVIS.exe`.
사용자 데이터: `%APPDATA%\LaVIS`.

## V-00 시작·상태바
- [ ] 첫 실행 시 상태바에 `[HH:mm:ss] 준비`가 보이고 프로그램이 즉시 응답한다(상태 메시지 스모크 — 뷰 상태 헬퍼 재귀 방지)
- [ ] 상태바 좌측 `OCR: …`이 엔진에 맞게 표시된다(AWS 인증 실패 시 빨강)
- [ ] 두 번째 인스턴스를 실행하면 "이미 실행 중" 안내 후 종료된다
- [ ] 상태바 `Rev.00 · v버전` 클릭 → About 오버레이(버전·빌드·데이터 폴더·로그), Esc/딤 클릭으로 닫힘
- [ ] 경고/오류 메시지가 5초간 정보 메시지에 덮이지 않고, `app.log`에 기록된다

## V-01 목록 생성 탭

- [ ] 리스트 생성 → 미리보기·경고/오류 패널(2/29 제조분이 있으면 행이 존재하고 EXP가 2/27)
- [ ] 엑셀로 저장 → 검사 탭 [목록 열기]로 다시 불러올 수 있다

## V-02 검사 탭 — PDF·OCR
- [ ] "검사 탭으로 보내기" → 탭 전환 + 목록 자동 로드
- [ ] PDF 열기(Ctrl+O 포함) → 상태바 진행 막대 `OCR n/N` 증가, 완료 후 페이지 이동이 지연 없음
- [ ] LOT 자동 매칭 표시(`자동(정확)` 등) + 규격 자동 선택; 규격 카드 토글이 파랑 테두리로 선택 표시
- [ ] **라벨에서 LOT을 못 읽는 페이지**: `⚠ 미매칭` 표시 + 상태바 경고 + 판정 '확인 필요'(바코드 검증 표에 'LOT 매칭' 불일치 행)
- [ ] 규격 수동 변경 → 재-OCR 없이 즉시 재판정, 그 페이지는 수동 선택이 유지됨
- [ ] 앱 재시작 후 같은 PDF 재오픈 → 디스크 캐시로 즉시 표시, AWS 콘솔에 Textract 호출 없음 **[무과금 검증]**
- [ ] 잘못된 AWS 프로필 → 상태바 빨강 `OCR: AWS 인증 실패`, OCR 실패 팝업은 같은 원인당 1회
- [ ] 판정 배지가 새 판정마다 앰버로 번쩍인 뒤 합격(녹)/확인 필요(주황)색으로 바뀐다

## V-03 검사 탭 — 저장·미저장 보호
- [ ] [결과 저장] → JPEG 저장 + 이력 행 추가, 파일명 `###_LOT_REF_날짜_판정.jpg`, 카운터가 재시작 후에도 이어짐
- [ ] 저장 후 팝업 없이 배지 플래시 + 상태바 `저장됨: …`
- [ ] 집계 줄에 `● 결과 미저장 N건`(빨강) ↔ 저장 후 `✓ 결과 저장됨`(녹색)
- [ ] 미저장 상태로 창 닫기 → 확인 대화상자, **Enter만 누르면 종료되지 않는다**
- [ ] 자동 저장 체크 → 즉시 설정에 저장되어 재실행 후 유지; 같은 페이지 왕복 시 중복 저장이 늘지 않는다(A-05 반영 빌드)
- [ ] 저장 폴더를 엑셀이 잠근 파일/권한 없는 폴더로 → 원인별 안내(팝업 또는 상태바 오류), 검사 결과는 유지

## V-04 바코드·GTIN
- [ ] DataMatrix는 청록 박스로 위치만 표시되고, 우측 하단 바코드 검증 표와 GTIN 카운트에 나타나지 않는다
- [ ] DataMatrix가 여러 개(크기·위치 다름), 라벨 하단·소형(모듈 2px 이상), 테두리 선·텍스트에 맞닿은 경우에도 박스가 그려진다
- [ ] GTIN 카운트는 인쇄된 `(01)+14자리` 텍스트 수(규격 기대 수)로 판정된다
- [ ] GS1-128 행: 값이 `(01)…(10)…(17)…`으로 풀려 보이고, GTIN이 기준 DB와 같으면 '일치'; (10) LOT이 다르면 '불일치'(붉은 행)
- [ ] FNC1 없이 인쇄된 GS1-128(LOT 뒤에 17이 바로 이어짐)도 '일치'로 표시되고 툴팁에 FNC1 안내가 있다
- [ ] 목록과 다른 라벨 → 바코드 불일치가 판정을 '확인 필요'로 만든다(불일치 행 붉은 배경)

## V-05 학습·교정·영역 (HFE)
- [ ] 필드 더블클릭(미검출) → 선택 대화상자에서 **Enter는 'OCR 로그 열기'**, 재OCR(과금)은 주황 버튼을 눌러야 실행
- [ ] OCR 로그에서 [선택 병합 학습] 후 창이 닫히지 않고 병합된 상태로 갱신, X/Esc로 닫으면 재검사
- [ ] 라벨 유형 이상 대화상자에서 **Enter만 누르면 학습되지 않는다**(`label_profiles.json` 불변)
- [ ] [✚ 필드 영역 등록] 켜기 → 커서 십자 + 상태바 안내, 드래그/클릭 등록 대화상자에 [취소]가 있고 Esc로 닫힘
- [ ] 설정 › 패턴 초기화(빨강) → 건수 표시 확인 대화상자, 기본 '아니오'
- [ ] 모든 모달 창(설정·OCR 로그·교정·기준정보 DB)이 Esc로 닫힌다

## V-10 규격 자동 선택 (라벨 문서번호)
- [ ] 목록에 STANDARD 열이 없어도 라벨의 `Rev.A00`이 읽히면 규격 A00이, `BSL-01`이 읽히면 BSL-01(Rev.5)가 자동 선택되고 '문서:' 줄에 `Rev.A00 → A00`처럼 표시
- [ ] 문서번호 영역에 보라 박스 `문서번호: …`가 그려진다
- [ ] PML-001 라벨: 문서번호 아랫줄의 `Rev.0` → PML-001(Rev.0), `Rev.1` → PML-001(Rev.1)이 선택되고 보라 박스가 두 줄을 감싼다
- [ ] `PML-001`만 읽히고 Rev가 안 읽히면 '문서:' 줄이 주황으로 후보(PML-001(Rev.1)/PML-001(Rev.0))를 안내하고 이전 규격이 유지된다; 규격 버튼으로 지정하면 그 페이지만 수동
- [ ] 문서번호가 없는 라벨(중국 등)은 '미감지 — … 유지'로 표시되고 이전 규격으로 검사된다
- [ ] 목록 생성 탭 미리보기·저장 파일에 STANDARD 열이 없고 날짜가 `yyyy-MM-dd`; BSC 규격으로 검사하면 라벨의 `yyyy.MM.dd` 날짜가 검출된다

## V-11 자동 검사 · 결과 목록 · 검사자 확인 합격
- [ ] [▶ 자동 검사] → 상태바에 `자동 검사 n/N · 합격 · 부적합` 진행, OCR 미완료 페이지는 기다림, 버튼이 `■ 자동 검사 중지`(주황)로 바뀌고 다시 누르거나 Esc로 중지
- [ ] 완료 후 결과 목록 창이 '부적합만 보기'로 열리고 요약에 부적합/합격/미검사 수가 맞다
- [ ] 결과 목록 행 더블클릭 → 해당 페이지로 이동; '부적합만 보기' 해제 시 합격 행(녹색)도 보인다
- [ ] 부적합 페이지에서 문제를 고치고(LOT 수동·교정·영역) F5 → 자동 합격이 되면 목록에서 부적합이 사라진다
- [ ] 여전히 '확인 필요'인 페이지를 선택 → [합격 처리 (검사자 확인)…] → 사유 입력 없이 확인하면 처리되지 않는다; 사유를 넣으면 배지가 `✓ 합격 (검사자 확인)`, 사유줄에 검사자·사유, 슬롯이 굵은 초록 테두리 ✓
- [ ] 합격 처리 후 저장 → 파일명 `_Passed`, 이미지 요약 박스에 `INSPECTOR PASS (auto CHECK)`, 이력 탭 판정 `합격(검사자)`, CSV `AUTO=CHECK / INSPECTOR=PASS / FINAL=MATCH / INSPECTOR_NOTE`
- [ ] [합격 처리 취소] → 자동 판정으로 복귀; 교정 등록 등으로 판정 근거가 바뀌면 상태바 경고와 함께 자동 해제
- [ ] 배지의 안내 문구(OCR 실패·목록 없음)가 한 줄 15px로 표시되고 잘리지 않으며, 긴 문구는 …과 툴팁으로 전문 확인
- [ ] 검출 필드가 아닌 단어에는 박스·신뢰도 %가 표시되지 않는다(저신뢰 파선은 검출 필드 단어에만)
