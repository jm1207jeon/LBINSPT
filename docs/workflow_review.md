# 작업 흐름 단계별 분해와 우선순위 검토

사용자의 목적: **"오늘 생산분 라벨이 기준정보와 정확히 일치하게 인쇄되었는지, 빠짐없이·빠르게 확인하고 증빙을 남긴다."**

## 단계 분해 (시작 → 종료)

| # | 단계 | 사용자의 의도 | 최우선 판단 기준 | 현재 구현 상태 / 이번 개선 |
|---|---|---|---|---|
| 0 | 기준정보 준비 | "정답지를 만든다" | **정답의 정확성** — 여기서 틀리면 전 단계가 무의미 | ✅ 목록 생성 탭 + **[신규] 기준정보 DB**: PN별 REF/GTIN/기대 심볼로지를 사전 등록, 목록과 자동 대조 |
| 1 | 검사 목록 생성 | "오늘 검사할 LOT 목록" | 누락 행 없음(2/29 등), 경고 가시화 | ✅ 행 이슈 패널, 무단 소멸 금지 |
| 2 | 목록 → 검사 전달 | 끊김 없는 이동 | 클릭 수 최소화 | ✅ 메모리 핸드오프 |
| 3 | PDF 로드 | "바로 검사 시작" | **대기 시간 체감 최소화** | ✅ 전 페이지 프리페치 + 캐시, [신규] 페이지 슬롯으로 진행 가시화 |
| 4 | 페이지별 검사 | "각 장이 맞는가" | **정확성 > 속도**: LOT 자동 추적, 오인식 구제 | ✅ 페이지별 LOT 자동 매칭, [신규] 혼동 문자 매칭 + 교정 학습, 기준DB 대조, 바코드 등급 |
| 5 | 이상 발견 시 | "왜 틀렸는지 즉시 확인" | 원인 가시성 (어떤 필드, 몇 회, 어디) | ✅ 필드별 카운트+오버레이, [신규] 박스 번호·스타일 설정, 오인식이면 더블클릭 교정 |
| 6 | 판정 확정·증빙 | "기록을 남긴다" | 파일 무결성(덮어쓰기 금지), 추적성 | ✅ 자동저장+이력 DB, [신규] CSV 내보내기 |
| 7 | 마감 | "오늘 몇 건, 문제 몇 건" | 요약 한눈에 | ✅ [신규] 대시보드 대형 카운터(합격/확인필요/진행), 이력 탭·LOT 리포트 |

## 순서/구조 판단

- **순서 변경 필요 없음** — 0→7 흐름 자체는 현장 순서와 일치. 다만 0단계(기준정보)가 기존에 "목록 생성 시 임시 생성"에 머물러 있어, 이번에 **기준정보 DB를 독립 단계로 승격**했습니다(사전 등록 → 목록·검사 양쪽을 대조).
- **추가된 것**: 페이지 상태 슬롯(4→5 이동 시 어디를 봐야 하는지), 교정 학습 루프(5→4 재검사), 마감 CSV(7).
- **우선순위 원칙**: ① 오판정 방지(거짓 합격 최소화) ② 재작업 최소화(오인식 구제·캐시) ③ 조작 최소화(자동 매칭·핸드오프) ④ 증빙 완결성.
