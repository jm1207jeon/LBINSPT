## 1. 현재 프로그램 규모 (실측)

| 항목 | 수치 |

244건, 오류 UX(자격증명 안내 등), 설정 마이그레이션, 배포 자동화까지 갖춘

## 4. 산정에 반영된 완성도 요소

1. **이중 구현 검증**: Python 참조 구현과 로직 패리티를 테스트로 상호 검증 —
   외주에서는 보통 제공되지 않는 품질 담보 방식 (산정에서는 C# 단일 구현
   기준으로만 계상, Python분 미포함).
2. **자동 테스트 244건**: 외주 계약에서 이 수준의 테스트 커버리지를 명시하면
   통상 개발비의 15~25%가 추가된다 (위 표에는 포함됨).
3. **운영 편의**: 설정 마이그레이션(무중단 업그레이드), 학습 데이터 이식,
   폴더 배포, CI 자동 빌드 — 유지보수성 항목으로 총액의 약 10% 상당.
