1 프로그램 소개

LaVIS는 라벨 인쇄 PDF를 읽어, 인쇄된 글자와 바코드가 주문 목록과 일치하는지 자동으로 대조해 주는 출하검사 보조 프로그램입니다. 검사자가 눈으로 하나씩 대조하던 일을 화면에서 한 번에 확인할 수 있게 정리해 줍니다.

이 프로그램이 하는 일

📋

검사 목록 생성

주문일정·품목번호·BSC 엑셀 3종을 합쳐 LOT·PN·REF·제조일·유효기간·GTIN 목록을 만듭니다.

🔍

라벨 자동 대조

PDF의 글자를 읽어(OCR) 목록과 대조하고, 필요한 횟수만큼 인쇄됐는지 셉니다.

▣

바코드 검증

GS1-128 바코드의 GTIN·LOT·유효기간을 목록과 대조합니다. DataMatrix는 위치만 표시합니다.

⚡

전 페이지 자동 검사

버튼 한 번으로 모든 페이지를 검사하고 부적합 로트만 모아 보여 줍니다.

🗂️

필드 모아보기

같은 항목(LOT·PN·REF…)의 인쇄 부분만 잘라 표로 모아 줍니다. 다른 값이 눈에 바로 띕니다.

💾

결과 기록

표시가 그려진 이미지, 검사 이력(DB), 전체 페이지 CSV로 남깁니다.

2 설치와 실행

LaVIS는 설치가 필요 없습니다. 공용 폴더에서 프로그램 폴더를 복사해 실행하면 끝입니다.

프로그램 위치

\\10.1.205.223\품질관리팀\01. 공용\C02 프로그램\LaVIS

탐색기 주소창에 붙여넣고 Enter를 누르면 폴더가 열립니다.

실행 순서

  1. 폴더를 내 PC로 복사

    공용 폴더의 LaVIS 폴더 전체를 바탕화면이나 C:\ 아래로 복사합니다. 네트워크 폴더에서 바로 실행하면 느리므로 복사해서 쓰는 것을 권장합니다.

  2. LaVIS.exe 실행

    폴더 안의 LaVIS.exe를 더블클릭합니다. 같은 폴더의 *.dll 파일과 models 폴더는 지우거나 옮기지 마세요.

    Windows에서 “PC를 보호했습니다” 경고가 뜨면 추가 정보 → 실행을 누릅니다.

  3. 바로 가기 만들기 (선택)

    LaVIS.exe 우클릭 → 바로 가기 만들기 → 바탕화면으로 옮기면 편합니다.

  4. 첫 실행 확인

    창 제목이 LaVIS - Label Verification & Inspection System Rev.00이고, 아래 상태바에 AWS 인증 확인됨 또는 OCR: 엔진명이 표시되면 준비 완료입니다.

설정과 학습 데이터는 어디에 저장되나요? 프로그램 폴더가 아니라 %APPDATA%\LaVIS(사용자별 폴더)에 저장됩니다. 그래서 프로그램 폴더를 새 버전으로 덮어써도 설정·교정·이력이 유지됩니다. 설정 창의 [설정 폴더 열기]로 이 폴더를 열 수 있습니다.

4 기본 사용법

하루 검사의 표준 흐름입니다. 익숙해지면 2 → 3 → 6만으로도 끝납니다.

  1. 검사 목록 준비 — ‘목록 생성’ 탭

    이미 만들어 둔 목록 xlsx가 있으면 이 단계를 건너뛰고 2단계에서 [목록 열기]로 불러오면 됩니다.

    ① [주문일정 체크리스트] · [제품 품목번호 리스트] · (일본 건이 있으면) [BSC FGD 리스트] 엑셀을 각각 선택합니다.
    ② 가운데 제조일 선택 트리에서 검사할 날짜를 체크합니다.
    ③ [리스트 생성] → 미리보기와 경고/오류 패널을 확인합니다.
    ④ [엑셀로 저장](보관용) 또는 [검사 탭으로 보내기 →](바로 검사).

    경고 패널을 꼭 보세요 “GTIN을 찾지 못했습니다”, “REF 셀이 날짜라 비웠습니다” 같은 경고가 있으면 그 LOT은 검사에서 확인 필요가 됩니다. 입력 엑셀을 먼저 고치는 편이 빠릅니다.

  2. 라벨 PDF 열기 — ‘라벨 검사’ 탭

    [PDF 열기]를 누르거나 PDF 파일을 창 안으로 끌어다 놓습니다(Ctrl+O).

    파일을 열면 모든 페이지의 글자 인식이 백그라운드로 시작됩니다. 툴바의 OCR 진행 3/12…가 OCR 완료 12/12 ✓가 되면 전부 준비된 것입니다. 기다리는 동안에도 페이지를 넘겨볼 수 있습니다.

  3. 자동 검사 실행

    [▶ 자동 검사]를 누릅니다. 첫 페이지부터 순서대로 검사하며 상태바에 자동 검사 5/12 · 합격 4 · 부적합 1처럼 진행이 표시됩니다.

    중간에 멈추려면 [■ 자동 검사 중지]를 누르거나 Esc. 그때까지의 판정은 유지됩니다.

    끝나면 결과 목록 창이 ‘부적합만 보기’ 상태로 자동으로 열립니다.

  4. 부적합 페이지 확인

    결과 목록에서 행을 더블클릭하면 그 페이지로 이동합니다. 원인을 이렇게 찾습니다.

    · 판정 배지 사유줄 — REF 12/13 · GTIN 바코드 불일치처럼 무엇이 문제인지 한 줄로
    · 필드별 검출 표 — ✗ 표시된 항목의 검출/기준 숫자
    · 필드 모아보기(우측 표) — 빨간 ‘미검출’ 칸, 주황 테두리(저신뢰) 칸을 찾습니다. 칸을 클릭하면 라벨의 그 위치로 화면이 이동합니다.

  5. 문제 해결하고 재검사

    증상해결
    글자를 잘못 읽음 (2S090776 등) 필드 표에서 그 행을 더블클릭 → 후보에서 올바른 값 선택 → 교정 등록. 이후 같은 오인식은 자동으로 고쳐집니다
    값이 두 조각으로 나뉘어 인식 [OCR 로그](Ctrl+Shift+L) → 두 단어 선택 → [선택 병합 학습]
    엉뚱한 곳의 글자가 잡힘 [✚ 필드 영역 등록] → 라벨에서 그 항목이 있어야 할 영역을 드래그 → 필드 선택. 이후 그 영역 안의 검출만 인정합니다
    LOT이 ⚠ 미매칭 Ctrl+L로 LOT 목록을 열어 직접 고릅니다
    규격이 잘못 선택됨 우측 규격 버튼을 직접 누릅니다 (그 페이지만 수동 지정)

    고친 뒤 F5로 재검사합니다. 합격이 되면 결과 목록에서 사라집니다.

  6. 검사자 확인 합격 처리 (필요할 때만)

    라벨을 눈으로 봤을 때 실제로는 정상인데 프로그램만 ‘확인 필요’로 표시하는 경우 (인쇄가 흐려 OCR이 못 읽은 경우 등)에 사용합니다.

    결과 목록에서 그 행을 선택 → [합격 처리 (검사자 확인)…] → 사유를 반드시 입력합니다. 사유가 비어 있으면 처리되지 않습니다.

    처리하면 판정이 ✓ 합격 (검사자 확인)으로 바뀌고, 사유·처리자·시각이 이미지·이력·CSV에 남습니다.

    실제로 부적합이면 합격 처리하지 마세요 라벨에 진짜 오류가 있으면 합격 처리하지 말고, 검사 기록지의 판정란을 부적합으로 고쳐 적고 불량 처리 절차를 따르세요.

  7. 결과 저장·기록

    · [결과 저장](Ctrl+S) — 현재 페이지의 표시가 그려진 이미지를 저장하고 이력에 남깁니다
    · [자동 저장] 체크 — 페이지 검사가 끝날 때마다 자동으로 저장합니다 (같은 판정은 한 번만)
    · [CSV 내보내기] — 전체 페이지를 한 줄씩 CSV로 (미검사 페이지도 포함)
    · 집계 줄의 ● 결과 미저장 N건이 사라지고 ✓ 결과 저장됨이 되면 완료입니다

▣ 바코드 인식 — 바코드를 클릭해 값 확인하기

라벨의 특정 바코드에 어떤 값이 들어 있는지 바로 확인하고 싶을 때 씁니다.

사용법 ① 툴바 [▣ 바코드 인식] 클릭 → 커서가 십자 모양으로 바뀌고 안내 배너가 뜹니다. ② 라벨 위의 바코드(DataMatrix 또는 GS1-128)를 클릭합니다. ③ 판독 결과 창에 종류 · 등급 · 판독값 · GS1 항목별 해석 · 현재 LOT과의 대조 결과가 나옵니다. ④ [값 복사]로 클립보드에 복사할 수 있습니다.

참고 · 드래그는 화면 이동으로 동작하므로 제자리 클릭해야 판독됩니다. · 자동 검출이 놓친 바코드도 클릭 지점 주변을 다시 읽어 찾아냅니다. · Esc 또는 버튼을 다시 눌러 해제합니다.

✚ 필드 영역 등록 — 검출 위치 제한하기

라벨의 엉뚱한 위치에서 값이 잡히거나, 특정 위치에서만 인정하고 싶을 때 씁니다.

① [✚ 필드 영역 등록] 클릭 → ② 라벨 위를 드래그(영역 지정) 또는 클릭(그 글자 상자를 그대로 사용) → ③ 대화상자에서 필드와 적용 규격(전체 또는 특정 규격)을 고릅니다.

등록하면 그 영역 안에서 검출된 것만 인정합니다. 등록된 영역은 파란 점선으로 계속 표시됩니다 ([영역 표시] 체크로 켜고 끔). 같은 필드에 이미 영역이 있으면 교체할지 추가할지 물어봅니다.

📄 OCR 인식 로그 — 실제로 읽은 글자 전부 보기

[OCR 로그] 또는 Ctrl+Shift+L. 그 페이지에서 프로그램이 실제로 읽어낸 모든 단어를 위에서 아래 순으로 보여 줍니다. 각 단어의 인식 신뢰도(%)도 나옵니다.

왜 검출이 안 됐는지 확인할 때 가장 확실한 방법입니다. 여기서 [선택 병합 학습](나뉘어 읽힌 값 합치기)과 교정 등록(오인식 고치기)을 할 수 있습니다.

🔧 미검출 진단 — 왜 못 찾았는지 알려주기

8 프로그램의 한계와 확인해야 할 사항

① 검사 기록의 판정란은 ‘P(합격)’로 기본 입력됩니다 — 가장 중요

검사 성적서·기록지의 판정란에는 합격(P)이 미리 채워져 있습니다. LaVIS는 화면과 저장 파일에 판정을 표시할 뿐, 기록지의 판정란을 대신 바꾸지 않습니다.

따라서 검사자는 반드시:

· LaVIS가 ‘확인 필요’로 표시한 페이지를 빠짐없이 확인하고
· 확인 결과 실제로 부적합이면 기록의 판정란을 부적합으로 직접 고쳐 적고
· 사내 불량·부적합 처리 절차를 따라야 합니다.

기본값 P를 그대로 두면 부적합이 합격으로 기록되어 출하될 수 있습니다. 자동 검사 후 결과 목록의 부적합 건수가 0인지 반드시 확인하세요.

프로그램이 실행되지 않아요

· “PC를 보호했습니다” → 추가 정보 → 실행
· DLL 오류 → 폴더 안의 *.dll이나 models 폴더를 지웠는지 확인. 공용 폴더에서 전체를 다시 복사하세요
· 이미 실행 중이라는 안내 → 작업 표시줄에 이미 떠 있습니다. 보이지 않으면 작업 관리자에서 LaVIS.exe를 종료 후 다시 실행

상태바에 “AWS 인증 실패”가 떠요

자격증명이 없거나 잘못됐습니다. C:\Users\사용자\.aws\credentials 파일을 확인하고, 설정 → 일반 · 저장 · AWS의 프로필 이름이 그 파일의 프로필과 같은지 보세요.

급하면 설정 → OCR 엔진에서 패턴 학습 또는 ONNX(로컬)로 바꿔 오프라인으로 검사할 수 있습니다. 인식률은 떨어지므로 결과를 더 꼼꼼히 확인하세요.

OCR이 계속 “진행 중”에서 멈춰요

네트워크나 AWS 응답이 느린 경우입니다. 같은 오류가 반복되면 프로그램이 남은 페이지 인식을 자동으로 중단합니다 (재과금 방지). 설정을 확인한 뒤 페이지를 이동하면 다시 시도합니다.

자동 검사 중이라면 3분간 진행이 없을 때 자동으로 중단되고 상태바에 안내가 나옵니다.

모든 페이지가 ‘확인 필요’로 나와요

· 규격이 잘못 선택됐을 수 있습니다. 우측 문서: 줄을 확인하세요. ‘미감지’나 ‘후보 …’면 규격 버튼으로 직접 지정합니다
· 기대 출현 횟수가 실제 라벨과 다를 수 있습니다. 설정 → 규격 · 양식 감지에서 검출 수에 맞게 조정하세요
· 목록의 값이 라벨과 다릅니다. 목록 생성 시 경고를 확인하세요

같은 오인식이 계속 반복돼요

필드 표에서 그 행을 더블클릭해 교정을 등록하세요. 한 번 등록하면 이후 모든 검사에 자동 적용됩니다.

등록한 교정은 설정 → OCR 엔진 · 교정 탭에서 확인·수정·삭제할 수 있습니다.

결과가 저장되지 않아요

· 저장 폴더가 네트워크 드라이브인데 연결이 끊긴 경우 → 자동 저장이 자동으로 꺼지고 경고가 뜹니다. [저장 경로]로 로컬 폴더를 지정하세요
· 권한 없음 / 파일 잠김 → 원인이 상태바에 표시됩니다. 해당 파일이 엑셀 등에서 열려 있는지 확인
· 검사 결과 자체는 유지되므로 경로를 고친 뒤 다시 저장하면 됩니다

설정을 잘못 바꿔서 되돌리고 싶어요

설정 → 규격 · 양식 감지 → [설정 폴더 열기] → settings.json을 삭제하고 프로그램을 다시 실행하면 기본값으로 돌아갑니다. (교정·이력 등 학습 데이터는 그대로 유지됩니다)

프리셋을 가져온 적이 있다면 backup-settings-시각 폴더에 이전 설정이 백업되어 있습니다.
