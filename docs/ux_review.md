## 2. UI/UX/HFE 개선 — 반영 완료

- **설정 창 탭 구조화**: 9개 그룹의 긴 스크롤 → 5개 탭(일반·저장·AWS / OCR 엔진·교정 /
  검출 필드·영역 / 규격·양식 감지 / 표시). 관련 항목이 한 화면에 모여 탐색 부담 감소.
- **단축키 가시화**: 검사 화면 헤더에 ←→·Home/End·WASD·Q/E·휠 안내 상시 표시
  (기억 의존 → 인지 의존, HFE 원칙).
- **모드 피드백**: 필드 영역 등록 모드에서 커서가 십자(+)로 바뀌고 상태바에 조작법
  안내. 모드 상태를 버튼 눌림 하나에만 의존하지 않도록 이중 신호.
- **범례 강화**: 화면 헤더 색 범례에 청록(바코드)·보라(양식) 추가 — 색만이 아니라
  텍스트 배지로도 구분되어 색각 이상 사용자도 식별 가능.
- **알람 피로 방지**: 동일 원인 오류 팝업 억제(위 #3) — 경고가 잦으면 무시하게 되는
  HFE 문제 예방.

## 3. 남은 개선 후보 (우선순위순)

1. **검사 결과 인쇄/PDF 리포트**: 현재 CSV·xlsx만 지원. 검사 완료 후 합불 요약 + 주석
   이미지를 한 장으로 출력하는 기능 (품질기록 보관용).
2. **사용자 구분·감사 추적**: 검사자 이름 기록, 설정 변경 이력 — 규제 대응(Part 11
   방향)의 첫 단계.
3. **설정 검색/즉시 도움말**: 설정 항목이 40개 이상 — 검색창과 항목별 "?" 툴팁 통일.
4. **첫 실행 안내(온보딩)**: AWS 없이도 시작할 수 있도록 첫 실행 시 OCR 엔진 선택
   마법사(AWS / 로컬 ONNX) 제시.
5. **고대비/큰 글꼴 모드**: 검사실 조명·거리 환경을 고려한 표시 배율 옵션.
6. **실행 취소(Undo)**: 영역 등록·병합·교정 등록의 되돌리기(현재는 설정 창에서 삭제).
7. **다국어(영문) UI**: 해외 사업장 배포 시.
